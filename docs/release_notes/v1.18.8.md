# Dapr 1.18.8

This update contains the following bug fixes and improvements:
- [Completed workflows created a reminder for every duplicate result](#completed-workflows-created-a-reminder-for-every-duplicate-result)

## Completed workflows created a reminder for every duplicate result

### Problem

When an activity result or external event arrived again for a workflow that had already completed, the sidecar created a wake-up reminder for the workflow. The reminder fired and ran a workflow turn with nothing to process.

### Impact

You were affected if you ran workflows whose activities could run more than once, for example after a sidecar restart or a placement change. After a fan-out workflow completed, each late duplicate result cost a reminder create in the Scheduler, a reminder fire and an actor turn.

### Root Cause

The sidecar drops a result that is already in the workflow's history or inbox, and creates the wake-up reminder again in case the first one was lost. It did this for completed workflows too, although a completed workflow never processes its inbox again.

### Solution

The sidecar acknowledges a duplicate result for a completed workflow without creating a reminder. A running workflow still gets its wake-up reminder.
